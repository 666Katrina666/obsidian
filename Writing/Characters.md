# DC

## Альфред Пенниуорт — всегда фон

Альфред в историях есть, но всегда фоном: он может появиться там, где ему естественно быть (подать ужин, открыть дверь, бросить реплику мимоходом), но сцены не про него. Сюжетных ролей, своих арок и ключевых разговоров он не получает, решения за героев не принимает и в разборах и предложениях по сюжету опорой не становится. Больше — только если это прямо сказано в запросе.

## Джейсон Тодд — Красный Капюшон

Позывной Джейсона по-русски — **Красный Капюшон**, не «Красный Колпак». Коротко — «Капюшон».

## Позывные в поле

В поле Бэтсемья друг к другу по именам не обращается — только по позывным («Капюшон», «Робин»). Полный позывной звучит не в каждой ситуации, прозвища допустимы (Джейсон зовёт Дамиана «демонёнок»), имена — нет. Даже Оракул по защищённому каналу называет их по именам редко.

## Разница в возрасте

Разница примерная и считается по году рождения. Она действует всегда, если запрос не меняет возраст явно: омоложение, перемещение во времени, перерождение, альтернативная версия персонажа (другое измерение, концепт Талона), возраст, прямо названный в запросе.

| Персонаж | Относительно Джейсона |
| --- | --- |
| Брюс | +20 |
| Барбара | +8 |
| Дик | +5 |
| Кассандра | 0 (на несколько месяцев старше) |
| Джейсон | 0 |
| Стефани | −1 |
| Тим | −2 |
| Дюк | −4 |
| Дамиан | −7 |

Если смерть и воскрешение Джейсона в истории были, учесть ещё и это. Биологически он примерно на полгода моложе своего возраста по году рождения: это время он пролежал в могиле. Психологически он моложе примерно на год: после воскрешения ещё около полугода длились диссоциация и кататония, до Ямы Лазаря.
