# Prompts — шаблоны запросов

Готовые формулировки, которые можно скопировать и дополнить. Правила письма в них не пересказываются — они живут в `StyleGuide.md`, шаблон только указывает, на что обратить внимание.

---

## Идея

```
Помоги проработать идею фанфика: [идея].
Сверяйся с Writing/StyleGuide.md и Writing/Characters.md, но не превращай их в чеклист.
Тон и форму выбирай под эту идею, а не под мои частые темы.
Сначала дай несколько разных направлений развития, потом помоги выбрать.
```

## Глава

```
Напиши длинную главу по плану: [план].
POV: [чей].
Опирайся на Writing/StyleGuide.md, особенно на ядро и §11 — удержание формы длинной главы.
Пиши по плану, развитие не додумывай.
Сохраняй характеры и конкретную динамику этой истории; не делай персонажей автоматически мягче, здоровее или терапевтически правильнее.
Ритм, телесность, прямоту диалогов, форму заботы и темп выбирай по самой сцене.
```

Для альтернативной главы добавить:

```
Это альтернативная [N] глава: предыдущие главы остаются каноном, меняется только [что].
```

## Убрать искусственность

```
Посмотри на этот фрагмент и убери искусственность. Сверяйся с Writing/StyleGuide.md, §13 — реестр антипаттернов.
Особенно проверь:
- стерильно-терапевтичные фразы и поведение, лишние разрешения на прикосновения;
- персонажи стали слишком мягкими или психологически «правильными»;
- переобъяснение уже показанных эмоций, ремарки, дублирующие реплику;
- рубленый ритм и каскады микрофраз без причины;
- повторяющиеся жесты как пиктограммы эмоций;
- эпитеты вместо имён, кальки с английского, идиомы-штампы;
- боль или конфликт исчезли только ради удобного завершения сцены.
Авторский текст меняй точечно, не переписывай целиком.

[фрагмент]
```
