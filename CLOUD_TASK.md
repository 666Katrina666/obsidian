# Задача для облачной сессии: обернуть голые запросы в оставшихся заметках `Fanfics`

Ветка `cloud/wrap-bare-prompts`. В ней, кроме заметок, лежат инструменты,
которых в `master` нет намеренно (там они в `.gitignore`): `Scripts/lib`,
`Scripts/tools/wrap_bare_prompts.py`, `convert_prompt_markup.py`,
`Scripts/tools/bare_prompts/helpers.py`, `tag_criteria/` (по ней скрипты
находят корень хранилища), карта `Notes/prompt_map.json` и правила `CLAUDE.md`.
**Прочитай `CLAUDE.md`** — общение и пометки на русском, тексты заметок не
переписывать.

## Цель

В каждой заметке `Fanfics` запрос лежит в свёрнутом callout
`> [!question]- Запрос N`, ответ — прозой следом. Сделано 261 заметка (в
карте, запись в `master` — коммит `ff02e1c`). Осталось ~135 заметок без
единого callout запроса (хабы — короткие заметки со ссылками `[[…]]` —
не трогать). Список: `python Scripts/tools/bare_prompts/helpers.py todo 200`.

Где запроса нет вовсе, ставится заглушка — callout с текстом
`(запрос не сохранился)` (решение автора). Где границы ответов не видны или
угаданы — поле `review` с причиной (одиночная заглушка помечается сама).

## Как работать (партиями по ~30, по номерам)

1. `helpers.py todo` — следующие заметки. Отложить гигантов (>5000 строк:
   `15.2`, `129.2`, `154.3`, `218.2`) на конец.
2. `helpers.py propose 80 <номера…>` — кандидаты: начало тела, заголовки глав,
   строки после концовок модели, строки, похожие на запрос (`?ЗАПРОС`).
   Кандидаты — подсказка, не решение. Решать по смыслу через
   `helpers.py show <номер> <a-b> …`.
3. Записать решения в JSON партии (номера строк файла, с единицы) и
   `helpers.py add batch.json`.
4. `python Scripts/tools/wrap_bare_prompts.py` — dry-run; отказов должно быть 0.
   Отказ «строк текста было N, стало M» — граница режет не там (например,
   внутри диапазона запроса есть строки-цитаты `>`, или запрос захватил `---`).
   Поправь или убери заметку из карты и запиши её в `review`-список ниже.
5. `python Scripts/tools/wrap_bare_prompts.py --apply`, затем
   `helpers.py verify HEAD` — расхождений 0.
6. Коммит партии: `git add Fanfics Notes/prompt_map.json`, сообщение
   `content(vault): wrap bare prompts in Fanfics N–M` (по-английски,
   автор — как настроен git, **без** строк `Co-Authored-By`). Пуш в эту же
   ветку `cloud/wrap-bare-prompts`. В `master` не пушить и не мёржить.

## Как отличить запрос от ответа (выведено на 10 партиях)

Запрос — текст автора: неформальный, часто со строчной буквы, со скобками
и уточнениями «(не пиши лишнего)», «(Джейсон смущен)». Ответ — текст модели:
оформленный, с заголовками, жирным, «Вот…», «Ниже представлен…», «Спасибо за
запрос!», «Ваша идея…», «Below is a chapter written in Russian…», `### Ответ`.

Виды запроса, которые уже встречались:
- голый абзац в начале тела или между главами: «напиши длинную главу…»,
  «следующая глава. …», «Напиши 3 главу», «давай напишем…», «перепиши.»;
- план/список автора без глагола перед главой («Брюс чувствует…», пункты
  сюжета), вводная-сеттинг в начале («Кроссовер DC и Danny Phantom (но из
  второго нет персонажей) / Бэтсемья: …»);
- заголовком: `## Напиши N главу`, `## Следующая глава` + `**Краткое
  содержание:**` + пункты, `## Запрос на написание главы N` (в склеенных
  заметках, заголовок входит в запрос);
- цитатой после концовки модели: `> **Следующая глава:** …`;
- запрос со вставленным куском прошлого ответа (списки возрастов, план
  главы «Глава 3: … / Содержание: …» перед настоящим заголовком главы) —
  всё это часть запроса, ответ начинается с настоящего текста модели;
- второй вид экспорта: запрос отбит строкой из одних пробелов.

Не запрос: «Примечания:», «Заметки по главе:», «Сохраняйте баланс…»,
«Если хочешь, могу…» (концовка модели — запрос идёт сразу после неё),
мусор интерфейса Grok («Thought for 1m 0s», «Expand for details»,
«20 web pages», «DeepSearch/Think») — оставлять в ответе.

Где ставить заглушку (запроса нет): начало тела, если оно — ответ; перед
каждой главой (`# Глава`, `### Глава: …`, `**Глава …**`, `Глава N: …`),
у которой нет запроса; перед новым ответом после концовки модели; перед
новым планом/отчётом. Отчёт «deep research» (`Ключевые моменты` / `Введение`
/ `Отчет` / `План глав`) — один ответ целиком. Пункты плана глав внутри
одного ответа — не отдельные ответы.

Скрипт не умеет резать строку: если запрос приклеен к концу строки ответа
(«…внимания.Напиши главу…»), обернуть целиком нельзя — поставь заглушку
перед следующей строкой и опиши склейку в `review`.

Два запроса подряд без ответа между ними — один диапазон (скрипт требует
ответ между запросами).
